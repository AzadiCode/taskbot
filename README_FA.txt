نسخه اصلاح‌شده جریان تسک کانال

تغییرات اصلی:
- تسک‌ها از طریق کانال نمایش داده می‌شوند.
- پست کانال دکمه «رفتن به پست مقصد» و دکمه سبز «دریافت پاداش» دارد.
- داخل ربات لینک رفتن به پست مقصد نمایش داده نمی‌شود؛ فقط توضیح کوتاه و دکمه سبز «انجام دادم؛ ثبت درخواست» نمایش داده می‌شود.
- بعد از ثبت، برای ری‌اکشن کانال وضعیت «در حال بررسی» نمایش داده می‌شود و در صورت دریافت افزایش معتبر شمارش، پاداش پرداخت و پیام ارسال می‌شود.
- دکمه‌های Inline از فیلد style رسمی Telegram Bot API برای رنگ‌های آبی (primary)، سبز (success) و قرمز (danger) استفاده می‌کنند؛ نمایش رنگ به پشتیبانی نسخه کلاینت تلگرام وابسته است.

تنظیمات لازم:
- TASKS_CHANNEL=@YourTasksChannel
- ربات باید در کانال ویترین ادمین و دارای دسترسی ارسال/ویرایش پیام باشد.
- MONGO_URI را برای نگهداری دائمی داده‌ها تنظیم کنید.

محدودیت مهم:
بررسی ری‌اکشن کانال بر اساس شمارش تجمیعی است و نمی‌تواند به‌طور قطعی ثابت کند کدام کاربر ری‌اکشن زده است. این نسخه از افزایش شمارش استفاده می‌کند و نباید آن را تأیید هویت فردی تلقی کرد.

اعتبارسنجی انجام‌شده: کامپایل نحوی Python موفق بوده است؛ تست زنده با توکن و کانال واقعی انجام نشده است.
