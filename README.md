# taskbot

TaskPlus — Telegram task-exchange bot (Flask + MongoDB, single file).

**v52 growth engine:** daily gift + streaks, lucky wheel, levels, achievements & invite ladder, weekly leaderboard with prizes,
smart reminders, golden hour, guided onboarding, quick-quantity / repeat-campaign, admin broadcast queue, growth analytics,
auto channel posts and a cross-worker job lock. See `README_FA.txt` for details and the optional environment variables.

Run: `gunicorn taskbot:app`
